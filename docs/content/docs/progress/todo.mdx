# 待办

更新：2026-11-06。当前方向为[图解跟着资料改](../../../产品定位与范围.md)，以下均为待完成事项。

1. 收集 3 个真实修订案例：数值修正、定义或关系变化、来源删除或冲突。保留两版资料、改前图和最终图，预先标注应改、必须保留和需人工判断的对象；材料不足时先积累样本。
2. 记录当前手工流程及一个可运行图解近邻的同题基线，包含首次导入、来源建链、修改、核对和导出的总人工耗时；无法运行的工具只作公开能力对照。
3. 样本具备后，按[首版设计与验证计划](../../../plans/2026-11-06-source-linked-diagram-design.md)实现一类流程图的来源绑定、资料比较、对象影响清单、人工确认、版本恢复和导出。原型采用本地清单与现成 SVG 渲染。
4. 检查语义改写、未关联变更、来源删除或冲突、过期提议与排版变化；未批准对象不得变动。
5. 完成 3 例对照及两位非开发试用者试用，按总耗时下降 30% 等完整门槛决定继续、缩减或停止；不能只计算第二轮省时。
6. 通过验证后，按[自部署迁移路线](../../../开源自部署目标与迁移路线.md)落实许可证、独立生产服务、统一部署机存储、旧数据迁移和备份恢复，再完成发行验收。

现有图片生成、参考图和画布作为素材创作基础。旧 Supabase／Cloudflare 托管路线、多用户协作和通用任务引擎不属于当前首版推进事项。
