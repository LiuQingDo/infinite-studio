# 待测试

更新：2026-11-06。本清单区分当前已有能力的待验收项与尚未实现的目标能力，不表示已执行测试。

## 图解方向：实现后待验证

- 用 3 个真实案例核对所有应改对象、必须保留对象和人工判断项，覆盖数值修正、定义或关系变化、来源删除或冲突。
- 检查一段关联多对象、一个对象依赖多段资料，以及没有绑定对象的新资料变更；无关联不得自动认定为无影响。
- 确认前原稿保持完整；确认后仅批准对象的内容、样式、位置或关系可变动；排版变化也需预览和确认。
- 资料或图在预览后变化时拒绝过期提议；来源无法定位或存在冲突时保留原稿并进入待核对状态。
- 保存重开、查看旧版、恢复旧版与项目导入导出后，核对对象 ID、原文、来源关联及修订记录；人工检查 SVG／PNG 的文字、布局和事实。
- 同题对照统计首次导入与建链在内的总人工耗时，单列第二轮修订、模型调用及费用；执行[首版计划](../../../plans/2026-11-06-source-linked-diagram-design.md)中的继续门槛和两位非开发试用者试用。

## 现有开发预览：持续待验收

- 配置真实图片服务后，验证生成、参考图编辑、取消、错误提示、结果复用、下载和刷新后恢复；本地或模拟接口检查不能代替供应商实测。
- 验证集成画布的新建、重命名、删除、引用图片、刷新恢复、窄屏和触控操作；项目仍有浏览器持久化依赖，不代表部署机保存已实现。

## 生产交付：实现后独立验收

- 独立 Node 服务、统一数据目录、原型与浏览器数据迁移、备份恢复、断网行为、外部请求和许可清单，按[迁移路线](../../../开源自部署目标与迁移路线.md)核验。
- 构建与自动化检查、真实设备体验、非开发者试用和新环境部署分别记录结果，不相互替代。
- 旧 Worker／Supabase 基础不作为新产品首版的发布依据；若未来重新启用，需另行设计和验证其身份、权限及数据隔离。
