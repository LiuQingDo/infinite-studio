# 产品定位与范围

本文档记录已确定的产品方向；目标用户和具体功能仍需验证。

## 产品方向

面向海外用户，建设覆盖多个专业领域的 AI 图片创作产品，视频生成为辅助方向。原创角色和品牌吉祥物是可探索的场景之一，首批行业、用户群和具体交互尚未确定。

采用路线 C：以自己的产品架构为主体，评估并吸收 infinite-canvas 和 Toonflow 的适用能力，不预设任一上游为最终主体。详情见[融合架构草案](融合架构草案.md)。

## 当前状态

外层继承自 infinite-canvas 的应用代码和配套文件已清理。现阶段尚无自己的应用代码、可运行网站、本站模型服务、账户或云端作品；参考项目的能力不等于本站已实现。

两个上游项目保存在 `reference-projects/`，只供只读参考。项目自己的新架构和开发计划待设计，详见[二次开发基础](二次开发基础.md)。

## 待明确

- 优先服务的海外地区、目标用户和专业图片场景。
- 网站入口、图片生成与编辑体验、画布和素材组织方式。
- 模型供应商、预算及用户作品保存方式。
- 产品技术架构、部署方式及后续视频能力的边界。
