# 产品定位与范围

> 2026-10-27｜本文件描述当前产品方向。需要验证的用户群和交互方式标为建议，不代表已经开发完成。

## 产品初衷

面向海外创作者，建设一个以角色和吉祥物为中心的 AI 内容创作产品。希望帮助用户围绕原创角色或品牌吉祥物制作图片，长期探索角色内容的持续创作和系列短视频。

角色内容是长期定位，不意味着当前已经具备角色一致性、角色档案或视频生成能力。目标用户、市场和商业模式均需进一步验证。

## 目标用户与使用场景

以下是产品假设，尚未经过用户研究验证：

- 拥有原创角色的独立创作者，希望用角色制作插画、表情或日常内容。
- 拥有吉祥物的品牌或商家，希望为宣传、社交内容制作图片。
- 小型内容团队，希望更方便地管理和复用已生成的视觉素材。

不同用户对角色一致性、商用授权和团队协作的需求可能不同，不预先承诺当前版本可以满足全部需求。

## 当前阶段

当前阶段围绕网站和图片生成，除图片业务外只做必要的基础能力：

| 产品能力 | 当前目标 | 状态 |
| --- | --- | --- |
| 网站界面 | 简洁清晰的中文创作界面，可借鉴即梦等成熟平台的布局和操作方式 | 已采用上游界面作为二开基础，尚未进行本地验收或产品界面改造 |
| 图片生成 | 输入描述，选择实际支持的必要参数，查看生成状态和结果 | 上游提供配置和调用入口；本站图片服务尚未接入，未做真实生成 |
| 账户与作品 | 满足登录和个人作品的查看、预览、下载、删除等必要需求 | 本站账户及云端作品尚未接入；上游本地素材不等于账户作品 |
| 状态与说明 | 对服务未配置、处理中、失败和保存状态给出真实说明 | 随实际接入实现，不用演示结果冒充真实作品 |

首轮主要业务不是视频、配音、字幕、支付或订阅。上游自带的画布、参考图、视频等功能是否展示、保留或纳入产品范围，尚未逐项确定；选择上游不等于要求删除其源代码或承诺开放全部功能。

## 创作体验方向

- 让用户能清楚地输入创作想法，参数选择尽量直观；参数是否可用以实际模型与服务端支持为准。
- 让结果成为主要视觉内容，清楚区分用户作品、示例和空状态。
- 参考即梦的创作入口、参数面板和内容组织方式，保留自己的品牌与视觉资产，不直接复制第三方标识或素材。
- 界面优先中文，开发完成后再加入并完善英文体验。原始目标仍面向海外，开发阶段的中文优先不等同于改变目标市场。
- 项目名称为 `infinite-studio`；标志和具体视觉样式尚未确定。

## 已知状态

当前工作区已替换为 [无限画布](https://github.com/basketikun/infinite-canvas) 仓库，Web 应用位于 `web/`，作为实际二开主体。上游源码和入口已保留；本机开发服务器已启动，尚未进行页面验收，不能把上游项目声明的功能直接当作本站已验收的能力。

旧 Astro 原型源码和构建产物已从同级备份中移入回收站；其认证、图片存储和供应商适配未迁移。旧配置示例、数据库迁移文件和项目文档仍保留，数据库迁移没有执行。模型调用、个人数据隔离和正式上线均不能因为存在代码而视为已验证。

## 待明确事项

- 目标海外地区和核心用户。
- 首轮是否开放上游的画布、参考图、素材等入口。
- 个人作品采用何种账户、存储和同步方式。
- 实际图片服务、预算、使用规则及部署位置。
- “语音优先中文”是否涉及语音输入或配音；目前仅明确界面中文优先，不将语音功能视为已确认需求。
