# 产品与界面设计方案

状态：产品方向已确认；页面结构、交互和优先级为设计建议，待场景、技术和用户验证。本文不代表功能已实现或已上线。

## 1. 产品方向

Infinite Studio 面向海外用户，以不同行业和创作任务的 AI 图片创作为核心。产品提供提示词模板，帮助用户从实际需求出发生成图片，也允许用户自由输入和编辑提示词。画布用于整理素材、比较结果和继续迭代；视频生成作为图片创作的辅助能力。

首批行业、地区、用户群、模板内容、供应商和预算尚未确定。商品图、品牌视觉、角色内容等仅是候选场景，不能视为已经选定的首发范围。

核心路径建议：

```text
选择行业或任务 → 选择模板或自由输入 → 填写需求 / 添加参考图
→ 生成图片 → 查看、挑选和修改 → 下载 / 保存 / 加入画布
→ 需要时从图片继续生成视频
```

## 2. 产品结构

| 层级 | 建议内容 | 目的 |
| --- | --- | --- |
| 公开网站 | 首页、行业与场景、模板展示、价格、登录 | 说明产品价值，帮助用户找到入口；价格方案待定 |
| 图片创作 | 模板创作、自由生成、图片编辑 | 完成主要创作任务 |
| 提示词模板库 | 行业和任务分类、搜索、详情、收藏、个人模板 | 发现适用方法并开始创作 |
| 我的作品 | 图片结果、任务状态、生成信息 | 找回并继续使用作品 |
| 画布项目 | 多图组织、参考关系、比较与迭代 | 承接复杂图片创作 |
| 素材库 | 上传素材和可复用的生成结果 | 在不同创作中查找、引用素材 |
| 视频创作 | 从图片进入视频生成及结果查看 | 辅助图片延伸，具体边界待定 |
| 账户与设置 | 账户、偏好及可用的使用情况 | 管理账户与服务 |

以上是信息架构建议，不要求全部作为首屏一级菜单。简单生成与画布应共享项目、素材、任务和作品的概念，避免用户换入口后丢失上下文；具体数据关系和保存策略待设计与验证。

## 3. 提示词模板库

### 3.1 发现方式

模板同时支持按行业和按创作任务浏览；一个模板可以属于多个分类。候选行业如电商、餐饮、美妆、服装、品牌设计；候选任务如商品展示、背景替换、海报、社交配图和角色设计。这些均为示例，不代表首批范围。

建议提供关键词搜索、分类和标签筛选、排序，以及适合场景的模板推荐。搜索无结果时应提示调整关键词或改用自由创作。正式产品以英文体验为主，具体地区与多语言策略待定。

### 3.2 模板卡片与详情

卡片建议展示示例图、模板名称、行业 / 任务标签、简短用途和“使用模板”入口，可提供收藏。详情展示适用任务、示例、输入项、参考图要求、建议比例、可查看和编辑的完整提示词，以及开始创作按钮。

示例应标识与实际结果相关的已知条件，例如使用的模型、参考图和设置；不承诺每次生成可复现。模板、示例图和第三方提示词来源需记录来源及使用许可，建立内容审核、更新和失效处理方式。是否接入第三方来源尚未决定。

### 3.3 可填写、可编辑、可复用

模板应像创作配方：先展示任务相关的少量输入项，再将填写内容组合为用户可查看、可编辑的提示词；保留直接使用、修改和另存个人模板的路径。自由创作不要求选择模板。

示例（仅说明交互，不是已验证模板）：

```text
模板：自然光商品展示
商品类型：护肤精华液     品牌风格：简洁、自然
场景：浅色石材台面       光线：柔和自然光
比例：4:5               参考图片：上传或从素材库选择
提示词：展开查看并编辑                    [开始创作]
```

模板使用的字段、提示词、示例和可用参数应独立管理；编辑后的最终提示词应能被用户检查。实际图片效果、商品文字和外形保留程度依赖模型与编辑方式，不能由模板本身保证。

## 4. 页面与核心流程

### 4.1 首页与工作台

公开首页以行业图片创作为核心，展示真实可用的案例、行业 / 任务入口和“浏览模板”“开始创作”。画布与视频作为后续能力介绍。案例必须与实际条件相符。

登录后的工作台可展示模板搜索、常用行业和任务、自由创作、最近作品及项目和任务状态。新用户应能直接开始，老用户应能回到上次创作。

### 4.2 图片创作

建议左侧为模板或提示词、参考图和设置，右侧为结果；自由创作复用同一页面，但不预填模板。默认展示最必要的输入，模型和高级设置按实际能力渐进展开。

结果可提供下载、再次生成、继续编辑、保存素材和加入画布；视频可在能力可用后提供。结果详情尽可能保留最终提示词、模板版本、参考素材、可用参数、任务状态及时间，使用户理解并继续创作。各项记录以实际支持和保存策略为准。

### 4.3 画布

画布为多素材、多版本和多步骤图片创作提供宽敞空间。空画布给出上传图片、输入描述和生成图片等明确入口；图片操作应靠近选中对象，素材库按需展开。可考虑图片、文字、生成任务、分组和连接，简单任务不强制用户学习连线。结果与参考关系能否完整恢复需实测。

### 4.4 视频辅助

候选流程为选择已有图片 → 描述运动及可用设置 → 提交 → 查看与保存结果。视频服务、模型、费用、输入限制与首发时间尚未确定，界面不得把未接通的能力表现为可用。

## 5. 视觉与交互方向

沿用现有预览的暖白、低饱和绿和克制的工作室气质，以作品为视觉重点。公开首页可更具品牌表现力；工作台强调任务入口；图片创作页与画布优先保证空间、清晰度和操作效率。颜色、字体、组件尺寸和最终视觉风格仍需原型验证。

按钮、图标与输入项应有清晰名称、键盘焦点及足够的文字对比；画布需考虑键盘替代操作。桌面端优先承载完整创作流程，移动端至少评估浏览模板、查看结果及下载的可用性；实际支持范围由设备测试决定。

## 6. 状态与反馈

- **空状态**：提供下一步操作，例如浏览模板、上传素材或自由输入。
- **加载与生成**：展示已知的排队、提交、生成或完成状态；无可靠进度时不编造百分比。
- **失败**：给出可理解的信息和可行的重试方式，保留用户输入及可恢复的参考素材。
- **保存**：明确保存中、成功或失败；不要让用户误以为未保存的作品已存储。
- **费用与额度**：提交前展示服务实际支持且可确认的信息；价格未定时不虚构。
- **删除**：说明删除对象和影响范围，区分从项目移除与删除源素材。

## 7. 推荐实施顺序

以下为建议顺序，并非已确认的发行承诺。账户、任务处理、数据隔离、存储和成本控制等基础能力需与图片闭环一同完成和验证。

1. 确定首批行业和任务，准备少量可审查、可验证的模板及示例。
2. 建立模板发现、模板输入与自由创作，完成真实图片生成、任务状态和结果查看。
3. 完成作品与素材的受控保存、找回和下载。
4. 建立基础画布，支持组织参考图和结果、继续创作。
5. 根据实际模型能力与用户测试选择图片编辑功能。
6. 在图片闭环稳定后评估视频辅助功能。
