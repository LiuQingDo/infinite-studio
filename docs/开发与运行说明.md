# 开发与运行说明

## 当前可用内容

- `apps/web`：React/Vite 中文工作区预览，包括示例模板搜索与分类、模板字段生成可编辑提示词、自由输入、参考图选择及基础画布。四个模板和装饰图仅用于说明交互，未经模型验证，也不是已选定的首发内容。画布可添加图片和文字并拖动或移除；参考图、提示词和画布均仅保存在当前页面内存，刷新或关闭页面即丢失，不会上传或生成作品。配置 Supabase 后可使用已有账号密码登录并查看最近任务。
- `apps/api`：Cloudflare Worker，`GET /api/status` 显示配置状态；`GET /api/tasks` 验证用户 token 并按用户读取最近任务；生成接口始终返回 503。
- `packages/contracts`：共享任务状态类型；`packages/providers`：仅供服务端使用的供应商接口定义，无实际供应商。
- `supabase/migrations`：任务、素材的只读 RLS 策略和私有桶读取策略。默认不允许客户端创建任务、上传或修改资源。

尚无队列生产者、消费者、定时恢复、事务性投递、预算预留、实际模型或作品上传。不要部署为可对外提供生成的服务；Worker 构建是 dry-run，不会部署。数据库迁移尚未在真实 Supabase 环境执行，权限策略也尚未实测。

## 在本机启动

使用 Node.js 22.12 以上和 pnpm 11。依赖脚本仅批准 `esbuild` 和 `workerd`。在项目根目录执行 `pnpm install`，然后分别在两个终端执行 `pnpm dev:api` 与 `pnpm dev`，打开 http://127.0.0.1:5173 。Vite 将 `/api` 代理至本机 Worker 的 8787 端口。无需账户即可体验模板、提示词编辑和临时画布；使用 Ctrl+C 退出各服务。

### 同时启动本项目和两个参考项目

Windows 下双击根目录的 `start-all.cmd`，或在终端运行 `node scripts/start-all.mjs`。保持窗口打开，按 Ctrl+C 停止本次启动的全部服务。启动器使用现有的同级目录 `../infinite-studio-reference-preview/` 中的参考项目运行副本和 Bun，不会修改 `reference-projects/` 的只读源码；需要事先准备该预览目录及三个项目的依赖。缺少文件或端口被占用时会显示原因并退出，不会安装依赖或结束已有服务。

| 项目 | 地址 |
| --- | --- |
| Infinite Studio | http://127.0.0.1:5173 |
| Infinite Canvas | http://127.0.0.1:5180 |
| Toonflow | http://127.0.0.1:5181 |

本项目 API 使用 8787 端口，Toonflow 服务使用 5191 端口。Toonflow 的数据位于运行副本的 `data/`；其已有设置或外部素材路径仍由 Toonflow 自己管理。

## 配置测试账户与数据库

仅在你选定的测试 Supabase 项目中操作：

1. 检查并应用 `supabase/migrations/20261027000000_foundation.sql`。这是新项目迁移，运行前确认目标库和权限；尚未提供生产迁移或回滚演练。
2. 将 `apps/web/.env.example` 复制为 `apps/web/.env.local`，将 `apps/api/.dev.vars.example` 复制为 `apps/api/.dev.vars`，分别填写同一项目的 URL 和 publishable key（旧项目可使用 anon key）。重启两个开发服务。浏览器变量只有公开 key；绝不填 service-role key 或模型密钥。
3. 使用该项目中已有的邮箱密码账户登录。当前没有注册、重置密码或第三方登录界面；这些需后续按产品需求实现。
4. 验证账号 A 与 B 不能读取彼此的任务和私有对象，包括直接访问 Supabase API；同时验证无 token、过期 token 的拒绝行为。迁移只授予读取权限，没有允许用户插入数据的策略。

`.env.local`、`.dev.vars` 和本地 Wrangler 数据不应提交。真实服务配置、账户创建、迁移执行和账单均未自动操作。

## 检查

在根目录运行 `pnpm typecheck`、`pnpm test`、`pnpm build`。构建包括前端打包和 Worker dry-run；自动测试覆盖未配置状态、生成关闭、缺少凭据的拒绝及模拟的已验证用户查询，不能替代真实 Supabase RLS、Storage 和设备测试。测试范围排除只读 `reference-projects/`。

生产部署尚需选择站点域名、把 `/api/*` 路由到 Worker 并为前端静态资源配置同源访问，同时设置环境变量、鉴权、速率与成本限制、日志、备份、隐私和发布流程。用户令牌不应通过不受信任的域名发送。
