# infinite-studio

面向海外用户的 AI 图片创作项目，视频能力作为辅助方向。当前已有可在本地运行的架构基础与工作区预览；真实图片生成、文件上传和云端服务尚未接通。

## 本地启动

需要 Node.js 22.12 以上和 pnpm 11。安装依赖后在两个终端分别启动：

```bash
pnpm install
pnpm dev:api
pnpm dev
```

访问 http://127.0.0.1:5173 。不配置 Supabase 也可以查看界面；账号、迁移和服务配置见[开发与运行说明](docs/开发与运行说明.md)。
